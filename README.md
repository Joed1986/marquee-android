# Marquee for Android

**Download:** [Marquee.apk](https://github.com/Joed1986/marquee-android/releases/latest/download/Marquee.apk)

1. Open the link above on your Android phone, tablet or TV (on a TV, use the Downloader app).
2. When it finishes downloading, open it and choose **Install**.
3. The first time, Android asks to allow installs from that app: tap **Settings**, switch on **Allow from this source**, then go back.
4. If Play Protect says the developer is unknown, tap **More details → Install anyway**.

Sign in with the code the app shows, at plex.tv/link. To update later, open the same link again and install over the old app.
